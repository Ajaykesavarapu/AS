# ASKreativ Global Solutions — Full Website Build Prompt

---

## 🎯 PROJECT OVERVIEW

Build a **full-stack, production-grade marketing website** for **ASKreativ Global Solutions** — an AI automation and digital marketing agency based in Hyderabad, India.

The website must be inspired by the **UI/UX structure and feel of https://shiftwave.com/** — including its layout architecture, scroll behaviors, section sequencing, sticky navigation, animated stats, service cards, client strips, process steps, FAQ accordion, and CTA sections — but fully redesigned using **ASKreativ's brand identity, color palette, content, and personality**.

### Typography
- **Display / Hero headings**: `Clash Display` or `Syne` (Bold, 700–800 weight) — modern, geometric
- **Body / Subheadings**: `DM Sans` or `Plus Jakarta Sans` — clean and readable
- **Accent / Labels**: `Space Mono` — for numbered labels, tags (e.g., "01 —")
- Import from Google Fonts or CDN

### Design Aesthetic
- **Dark, premium, futuristic** — deep navy/black backgrounds with orange and gold accents
- Subtle **animated gradient meshes** in hero sections
- **Glassmorphism cards** with orange glow borders on hover
- **Orange underline / accent lines** as section dividers
- Smooth **scroll-triggered fade-in and slide-up** animations on all sections
- Staggered reveal animations on lists and cards
- Custom **scroll progress bar** (orange, top of page)
- Sticky navigation with **blur backdrop** on scroll
- **Cursor glow effect** (subtle orange radial glow following cursor on desktop)

## 🏗️ TECH STACK

### Frontend
- **Next.js 14** (App Router) — SSR + SSG for SEO
- **TypeScript**
- **Tailwind CSS** + custom CSS variables
- **Framer Motion** — page transitions, scroll animations, staggered reveals
- **GSAP** (optional) — for hero text animation and number counters

### Backend / CMS
- **Contentful** or **Sanity.io** — CMS for blogs, FAQs, services (structured content)
- **Next.js API Routes** — for contact form handling
- **Nodemailer** or **Resend** — email on form submission
- **Vercel** — deployment (with edge functions)

### SEO (Technical)
- `next/metadata` API for meta tags per page
- Structured data (JSON-LD): `Organization`, `LocalBusiness`, `WebPage`, `FAQPage`
- `sitemap.xml` and `robots.txt` auto-generated
- Open Graph + Twitter Card images per page
- `next/image` for all images (WebP, lazy loading)
- Canonical tags on all pages

## 📱 RESPONSIVE DESIGN REQUIREMENTS

| Breakpoint | Behavior |
|---|---|
| Mobile (< 640px) | Single column, full-width CTAs, hamburger nav |
| Tablet (640–1024px) | 2-column grids, condensed nav |
| Desktop (> 1024px) | Full multi-column layouts, megamenu |
| Large (> 1440px) | Max-width container 1280px, centered |

- Touch-friendly tap targets (min 44px)
- No horizontal scroll on any breakpoint
- Swipeable service cards on mobile (use Embla Carousel or Swiper.js)

## ✨ ANIMATIONS & INTERACTIONS

### Page Load
- Logo fades in first (300ms)
- Nav links stagger in (50ms delay each)
- Hero heading character-by-character reveal (Framer Motion `staggerChildren`)
- Hero subtext and CTAs fade up after heading

### Scroll Animations (all sections)
- Section headings: fade up + slide from bottom
- Cards: staggered fade-in (100ms delay per card)
- Process steps: alternate left/right slide-in
- Stats: count-up numbers (Intersection Observer trigger)
- Story lines: sequential fade-in on scroll

### Hover States
- Nav links: orange underline slides in from left
- Service cards: border glow + `translateY(-4px)` + arrow slides right
- CTA buttons: slight scale + background color shift
- Footer links: orange color transition

### Cursor (Desktop only)
- Custom circular cursor: small white dot + larger orange ring (slightly delayed)
- Orange ring scales up on hover over interactive elements

## ⚡ PERFORMANCE REQUIREMENTS

- Lighthouse score: **95+** on all metrics
- `next/image` for all images (WebP, AVIF, lazy loading, blur placeholder)
- Critical CSS inlined
- Font subsetting (only required characters)
- Defer non-critical JS
- No layout shift (CLS < 0.1)
- First Contentful Paint < 1.5s

## 🔒 CONTACT FORM & BACKEND

- Form submissions → API Route `/api/contact`
- Validate with **Zod** (server-side) + **React Hook Form** (client-side)
- Email via **Resend** or **Nodemailer** with SMTP
- Send confirmation email to user + notification to ASKreativ team
- **Honeypot** field for spam protection
- **Rate limiting** (max 5 submissions / IP / hour)
- Store leads in **Supabase** or **Airtable** (optional)
